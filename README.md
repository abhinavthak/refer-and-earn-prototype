# Refer and Earn Prototype

A clickable prototype of a referral programme for an online university. Referrers share a personal link, friends get a discount on their fees, and referrers earn e-gift cards when friends enrol.

**Live demo:** https://abhinavthak.github.io/refer-and-earn-prototype/

**Product requirements:** see [PRD.md](PRD.md)

## Screens

Use the **View** bar at the top of the page to switch between them.

| Screen | What it shows |
|---|---|
| Referrer site | Landing page: how it works, invite link sign-up, reward simulator, leaderboard, programmes, FAQ |
| Referrer dashboard | Friends table with stage, gift card and status, invite link sharing, gift card levels |
| Friend's referral link | What an invited friend sees: discounted programme price, counselling form, FAQ |
| Admin / white-label | Referrals, referrers and payouts, plus branding and reward-tier settings |

## Notes

- **Prototype only.** "Northbridge University Online" is a fictional brand. Forms do not send data anywhere, and the demo OTP is `1234`.
- All data (people, referrals, leaderboard, stories) is sample data.
- Everything runs in one `index.html` with no build step. Images are in `img/`.
